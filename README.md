# 📚 IT002.F11.CN1.CNTT - OOP
## Object-Oriented Programming (Lập trình Hướng đối tượng)

### Mục tiêu của Repository
Repository này được tạo ra để lưu trữ và quản lý toàn bộ tài liệu, bài tập, slide bài giảng và mã nguồn minh họa trong suốt khóa học IT002.F11.CN1.CNTT.

Nội dung được tổ chức theo từng tuần học/buổi học để dễ dàng theo dõi và ôn tập.

### 📁 Cấu trúc Thư mục

| Thư mục/File | Mô tả |
| :--- | :--- |
| **Bài tập TH** | Chứa các bài tập thực hành, code mẫu và solution (nếu có) của các buổi thực hành. |
| **Slide Bài TH** | Tài liệu trình chiếu (slides) sử dụng trong các buổi thực hành. |
| **Slide Bài giảng** | Tài liệu trình chiếu (slides) chính thức của các buổi lý thuyết (Thứ 5). |
| **Buoi [1-9].txt** | Ghi chú nhanh (notes) hoặc tổng hợp kiến thức trọng tâm của từng buổi học. |
| `note.txt` | Ghi chú chung, việc cần làm (TODO list) hoặc các tài nguyên ngoài. |
