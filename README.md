# 📚 IT002.F11.CN1.CNTT - OOP
## Object-Oriented Programming (Lập trình Hướng đối tượng)

### 🤔 OOP Là Gì? (Tóm tắt nhanh)
**Lập trình Hướng đối tượng (Object-Oriented Programming - OOP)** là mô hình lập trình tập trung vào khái niệm **Đối tượng (Object)**, cho phép tổ chức phần mềm thành các mô hình đối tượng thực tế.

Nền tảng của OOP được xây dựng trên 4 Trụ cột chính (Pillars):
1.  **Tính Trừu tượng (Abstraction):** Chỉ hiển thị những gì cần thiết, che giấu sự phức tạp.
2.  **Tính Đóng gói (Encapsulation):** Gói dữ liệu và phương thức xử lý dữ liệu vào một đơn vị (Class).
3.  **Tính Kế thừa (Inheritance):** Cho phép lớp con thừa hưởng thuộc tính từ lớp cha, giúp tái sử dụng mã.
4.  **Tính Đa hình (Polymorphism):** Cùng một tên hàm có thể thực hiện các hành vi khác nhau tùy thuộc vào đối tượng.
